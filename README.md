# Pepersfight

Birds vs Peppers seed royale, built in Unity 6 with Netcode for GameObjects.

- **Play in the browser:** https://nos-and-stealzers.github.io/pepersfight/
- **Windows download:** see [Releases](https://github.com/Nos-and-Stealzers/pepersfight/releases)
- **Official server:** `pepersfight.stealzerslab.fun` (WebSockets over Cloudflare Tunnel). Use **PLAY ONLINE**.

## Controls
WASD move, Space jump/glide, Shift sprint, Ctrl crouch, LMB fire, RMB aim, R reload, E interact/vendor,
1-5 slots, F trowel, Q build (Z X C V pieces, G material), Tab inventory (drag and drop), ~ players,
M map, B N J K L emotes.
